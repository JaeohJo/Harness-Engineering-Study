# Antigravity CLI Harness Engineering Framework (`agy-harness`)

A production-grade, extensible **Harness Engineering** system tailored for the **Antigravity CLI (`agy`)**.

This framework wraps Antigravity AI agents with an automated **Execution, Sandboxing, Guardrails, Evaluation, and Telemetry** pipeline to enable rigorous benchmarking, CI/CD regression testing, and autonomous task verification.

---

## 🚀 Key Capabilities

1. **Headless CLI Streaming Runner (`harness.runner.CliRunner`)**
   - Non-interactive execution using `agy --print --output-format stream-json`.
   - Real-time line-by-line NDJSON event deserialization (`thought`, `tool_call`, `delta`, `done`).
   - Clean process lifecycle management with `SIGTERM` / `SIGKILL` timeout escalation.

2. **Isolated Environment Sandboxing (`harness.environment.GitWorktreeEnvironment`)**
   - Automatically provisions an isolated Git worktree for every task run (`git worktree add`).
   - Automatically extracts unified diffs (`git diff HEAD`, including untracked files).
   - Zero side-effects on the host workspace with atomic teardown and branch pruning.

3. **Active Lifecycle Guardrails (`harness.guardrails.HookManager`)**
   - Injects `.agents/hooks.json` and Python security scripts into the task workspace.
   - `PreToolUse` security hooks intercept destructive shell commands (e.g. `rm -rf /`, raw device manipulation, reverse shells, `.git` destruction).
   - Enforces workspace guidelines via dynamically generated `GEMINI.md`.

4. **Automated Verification Engine (`harness.evaluator.TestEvaluator` & `DiffEvaluator`)**
   - Performs AST syntax validation on all modified Python files before test execution.
   - Applies evaluation patches (`test_patch`) cleanly and runs test suites.
   - Classifies task results: `PASS`, `FAIL`, `ERROR`, or `TIMEOUT`.

5. **Deep Telemetry & Observability (`harness.telemetry.TranscriptParser`)**
   - Discovers and parses conversation transcripts (`transcript.jsonl`) generated by Antigravity Brain.
   - Computes reasoning effort (Thinking token estimates), tool usage frequency, and conversation turn counts.
   - Generates comprehensive Markdown and JSON benchmark reports.

## 🛠 Installation

```bash
# Clone and create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install in editable mode with development dependencies
pip install -e ".[dev]"
```

---

## 💻 CLI Usage

### 1. Initialize Configuration
Generate default `harness.yaml` and `sample_tasks.json`:
```bash
agy-harness init
```

### 2. Run a Single Task
```bash
agy-harness run --task sample_tasks.json --model gemini-1.5-pro --effort high
```

### 3. Run Benchmark Suite
```bash
agy-harness benchmark --dataset sample_tasks.json --output reports/
```

---

## ⚙️ Configuration (`harness.yaml`)

```yaml
output_dir: reports
runner:
  model: null                       # e.g., gemini-1.5-pro
  effort: high                      # low | medium | high
  mode: accept-edits                # accept-edits | plan
  dangerously_skip_permissions: true # Auto-approves tools in headless mode
  sandbox: false                    # Enable agy internal terminal sandbox
  timeout_seconds: 300.0            # Task timeout
  agy_bin_path: agy                 # CLI executable name or path
  extra_flags: []
cleanup_worktree: true              # Clean up temporary worktrees after run
enable_guardrails: true             # Inject .agents/hooks.json safety guards
concurrency: 1
```
